# Data sources

The sprites in the `sprites` config, and the scenes built from them, come only from the packs below. Only use assets whose individual source page provides a compatible licence: "free download" and public visibility are not licences.

`downloaded-data/manifest.csv` records every sprite with its label, creator, licence and source URL. The scene generator uses only the CC0 sprites; the `sprites` config also holds the game-icons.net icons, which are CC BY 3.0 and credited per icon. Record each new pack separately, since an artist may publish other work under different terms.

| Creator | Pack | Verified licence |

Board Game Icons and Game Icons: objects only, not interface actions. 1-Bit Platformer Pack: whole objects only |
