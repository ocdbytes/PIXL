# Sprite sources

Pixl uses sprites from the packs below. `downloaded-data/manifest.csv` records each sprite's label, creator, licence and source URL.

| Creator | Pack | Licence |
|---|---|---|
| [Kenney](https://kenney.nl/assets) | 1-Bit Pack, 1-Bit Platformer Pack, Board Game Icons, Cursor Pixel Pack, Game Icons, Monochrome Pirates, Pico-8 City, Pixel Shmup, Pixel Vehicle Pack, Tiny Battle, Tiny Dungeon, Tiny Farm, Tiny Town | CC0, confirmed by [Kenney support](https://kenney.nl/support) |
| [ansimuz](https://ansimuz.itch.io/sunny-land-pixel-game-art) | Sunny Land | CC0 1.0 |
| [Buch](https://opengameart.org/content/a-platformer-in-the-forest) | A Platformer in the Forest | CC0 |
| Dungeon Crawl Stone Soup artists, maintained by Chris Hamons ([OpenGameArt](https://opengameart.org/content/dungeon-crawl-32x32-tiles-supplemental)) | Dungeon Crawl 32x32 tiles, Full (original and supplemental) | CC0 |
| [game-icons.net](https://game-icons.net/about.html) contributors ([repository](https://github.com/game-icons/icons)) | Game Icons (SVG) | CC BY 3.0; Viscious Speed and Zeromancer icons are CC0 |
| [GrafxKid](https://grafxkid.itch.io/mini-pixel-pack-3) | Mini Pixel Pack 3 | CC0 1.0 |
| [Idylwild](https://opengameart.org/content/idylwilds-inventory) | Idylwild's Inventory | CC0 |
| [Jull](https://opengameart.org/node/50777) | Animated spaceships | CC0 |
| [Scrittl](https://opengameart.org/content/spaceship-set-32x32px) | Spaceship set 32x32px | CC0 |
| [wender](https://opengameart.org/node/176168) | Sports cars pixelart sprites | CC0 |

The scene generator uses only CC0 sprites. The `sprites` dataset also includes the CC BY 3.0 game-icons.net icons, with credit stored per icon. CC0 attribution is optional, but Pixl keeps the creator and source in its manifest.
